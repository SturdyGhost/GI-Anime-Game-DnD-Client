Patch 3.4

Offline Mode

The client no longer bricks when you can't connect to the host. A new "Play Offline" button in the lobby lets you continue playing locally with your own save data. Changes you make offline sync automatically when you reconnect in a future session.

  • How it works: Every time you successfully connect to the host, the client saves a snapshot of your data locally. When you go offline, it loads from that snapshot. If you've never connected before, a bundled default save is included with the client.
  • Players in offline mode can access the full hub — swap equipment, gather materials, visit the market, view companion kits, and change their region. The Combat button is replaced with a Manage Inventory panel where you can add/remove weapons, artifacts, and items from the full GameDB list.
  • DM in offline mode can set up and run full battles — add enemies, process turns manually for each player, and manage the battle end-to-end. The Party Management tab is disabled (players manage their own stuff in offline mode).
  • Merge on reconnect: When everyone comes back online, each player's offline changes are automatically submitted to the host before the full sync. The host applies them and broadcasts the merged save to everyone. No manual file exchange needed.
  • Multiple offline sessions: If you go offline multiple times between connections, your changes accumulate. Each new offline session replays your pending changes on top of the latest snapshot so you always see your current state.
  • Mora: Everyone can edit mora in offline mode (coordinate verbally). On merge, the highest mora value across all submissions wins to prevent accidental loss.
  • Offline indicator: A red "OFFLINE" label shows in the hub so you always know your connection status.
  • Disconnect handling: If your connection drops mid-session, the client returns you to the lobby instead of showing an endless reconnect popup. From there you can try to reconnect or go offline.

Battle Simulator

A full battle simulation engine is now built into the client. It can run thousands of simulated battles using the actual game mechanics — dice rolls, damage formulas, weapon effects, talent bonuses, reactions, and smart AI for ability selection and targeting.

Post-Turn Damage Breakdown

After every turn in a real battle, a popup now shows what the system calculated as the possible outcomes for your attack. This appears for the acting player (DM sees enemy turns).

  • Shows your actual damage dealt prominently at the top for each target.
  • Below that, a table of every possible damage roll value with the calculated damage after modifiers (flat bonuses, multipliers, multi-hit reduction all applied).
  • The system estimates which roll you likely got and highlights it — marked as "EST." since it may not account for every active modifier.
  • Useful for seeing if you rolled above or below average on any given turn.
  • Dismissible with a close button, no auto-timeout.

Practice Mode (Player Hub)

The Practice button on the player hub hotbar now opens a full battle simulator. Set up any encounter, tweak your loadout, and run up to 10,000 simulated battles to see how your build performs.

  • Encounter setup: Add any enemies from the GameDB with a searchable dropdown. Set how many of each enemy type you want to fight.
  • Loadout overrides (sandbox only — never changes your real data):
    • Swap between your available kits (element + weapon type combinations)
    • Swap companion, weapon, and food buff
    • 5 individual artifact slots showing your currently equipped piece with dropdown to swap to any other artifact of the same type in your inventory
    • Hover tooltips on weapons show stats and effect descriptions, artifacts show stats and set bonuses
  • Stat overrides: Manually set any stat (Attack, Defense, EM, ER, Crit Damage, Health) to a custom value for "what if" testing. Pre-filled with your current calculated values. Toggle each one individually.
  • Damage modifiers: Separate player and enemy damage multiplier sliders (0.5x–1.5x) to calibrate the simulator against what you actually see in real battles.
  • Results panel:
    • Win rate, total wipes, and average rounds at a glance
    • Damage distribution bar graph with party and enemies shown separately, gold average line per group
    • Per-battler performance table with above/below average arrows (enemies compared to other enemies, party compared to party)
    • Ability breakdown per character showing uses, average damage, and total damage
    • Battle statistics grid (min/max rounds, zero deaths %, full wipe %, perma-death %)
    • Per-player recommendations analyzing stats vs performance — tells you if you need more Attack, EM, Defense, etc.
  • Single-screen iteration: Change any setup value and hit "Run Again" — results update in place. No navigation back and forth.

Encounter Balancer (DM Hub)

A new Encounter Balancer button on the DM Hub opens a simulator focused on tuning enemy difficulty. Select an enemy, pick a target difficulty tier, run simulations, and get advisory suggestions for stat adjustments.

  • Target difficulty tiers with fixed profiles:
    • Common: ~99% win rate, 1-2 rounds per enemy, no resources needed
    • Uncommon: ~95% win rate, 3-5 rounds, occasional items
    • Rare: ~85% win rate, 5-8 rounds, revives occasionally needed
    • Epic: ~80% win rate, 8-12 rounds, all revives burned in most fights
    • Boss: ~75% win rate, full wipe ~25%, all revives burned in half of wins
    • Legendary: ~50% win rate, full wipe ~40%, clean wins rare
  • Profile comparison: Horizontal bars showing actual results vs tier targets with gold target markers.
  • Advisory suggestions: Specific recommendations like "Increase HP from 120 to 145" or "Increase Attack Dice" with reasoning and expected impact. Marked as advisory only — the DM applies changes manually.
  • Profiles scale with encounter composition — 4 common enemies together shifts expectations appropriately.

Combat Mechanics in the Simulator

The simulator implements the full combat system:

  • Damage formula: Stat → dice → accuracy roll vs defense roll → difference → damage die → roll → flat mods → mult mods → multi-hit reduction (1/3 per successive hit, ceiling division, minimum 1).
  • Crits: Accuracy roll of 20+ is a crit. Crit damage multiplier applies.
  • Weapon effects: All 47 weapons with effects are active — Prototype Archaic's repeat attack, Sacrificial cooldown resets, Aqua Simulacra's damage bonus, Staff of Homa's HP scaling, etc.
  • All 20 chosen talents across every kit/element are implemented — Brian C.'s escalation chain with Push Further and Lucky Collapse, Brian F.'s Measured Wind-Up, Dylan's basic attack burst generation, and more.
  • Brian C.'s Nature Skill escalation fully simulated — d4→d6→d8→d10→d12→d20 chain with passive HP spending to reduce thresholds.
  • Companion rolls: Each player rolls their own dice independently, companion uses the average of those results (not one die from an averaged stat).
  • Smart AI: Prioritizes reviving downed allies → burst when charges full → skill/charged for max damage → basic attack → move only. Targets lowest HP enemy. Respects root/slow status, spatial distance, ability range, and built-in movement.
  • Spatial model: Simplified distance-based positioning. Players start at one end, enemies at the other. Movement, range checks, and melee/ranged distinctions all factor into AI decisions.
  • Reactions: Element application and reaction damage bonuses from the effect system.
  • Status effects: Stun, root, slow, and other status effects applied from abilities.

Resource & Role Rework

The entire resource gathering loop has been redesigned. Standalone gathering is gone — materials now come from combat, expeditions, and challenge quests. Roles rotate randomly each session instead of being permanently assigned.

Automated Combat Loot

After every battle, each player receives individual loot based on the encounter difficulty and the region it took place in.

  • Difficulty scoring: Each enemy contributes a score based on tier (Common=1, Uncommon=2, Rare=5, Epic=8, Boss=25, Legendary=40). The total score determines your loot tier.
  • Loot tiers: Range from Scraps (score 3-5, 2-3 per material, 1 cache) up to Abundant (score 40+, 16-20 per material, 2 caches). Each cache contains 4 material types pulled from the battle's region.
  • Luck modifier: Your daily luck stat adjusts quantities — high luck (85+) gives bonus materials, low luck (below 25) reduces them.
  • Loot display: A new section on the battle summary screen shows each player's individual loot after every fight.

Challenge Quests

System-generated optional objectives that give battles a secondary goal beyond winning. Completing the challenge earns bonus loot for the entire party.

  • Auto-generated: Before each battle, the system creates a random challenge — trigger a specific reaction, defeat an enemy with a charged attack, win within a turn limit, avoid taking crits, apply multiple status effects, etc.
  • Quest givers: Each challenge comes from a named NPC with a personality trait (generous, fair, stingy) that affects reward quality. Players see the quest giver and personality but not the actual reward values.
  • DM confirmation: After the battle, the DM gets a popup showing the challenge and Yes/No buttons to confirm whether the party completed it.
  • Visible in battle prep: The active challenge is displayed on the battle preparation screen so players can plan around it.
  • DM override: The DM can modify any aspect of the generated challenge before battle.

Role Rotation

Roles are no longer permanently assigned. After each battle scenario, the client randomly assigns one role to each player.

  • Three roles: Artisan (crafts food/consumables + artifact forge), Blacksmith (crafts weapons), and Scout (receives intel from the DM about upcoming threats and enemy weaknesses).
  • Scout replaces Scribe: The timed memorization/research mechanic is removed. The Scout role is about receiving verbal intel from the DM at the table — the client simply shows who has the Scout role.
  • Random each rotation: With 3 players and 3 roles, each player gets exactly one role per rotation. Displayed in the hub.
  • Crafting recipes unchanged: All 362 recipes remain. Role-gating still applies — which player is gated to which role just changes each rotation.

Companion Expeditions

Inactive companions can now be sent on expeditions between sessions to gather materials and resources.

  • Expedition slots: Number of slots equals twice the party's highest ascension level. Scales with progression.
  • Random expedition pool: Each time the party enters town, a pool of available expeditions is generated. Different missions, different optimal companions each visit.
  • Companion traits affect results:
    • Region affinity — bonuses in their home region
    • Weapon type — claymore for mining/ore, bow for hunting/foraging, catalyst for research
    • Element — Pyro bonus in volcanic/desert, Hydro in coastal, Dendro in forests
    • Personality — enthusiastic/diligent = more materials, lazy = less but occasional rares, scholarly = research bonuses
  • Results: Delivered next session. Primarily materials with occasional rare finds. Trait bonuses increase quantity and quality.
  • Expedition panel: New UI in the player hub for assigning companions to expeditions and viewing results from previous sessions.

Food Buffs Wired Into Combat

Active food buffs now actually work in battle. When a food buff is active, its GameEffect is registered in the EffectProcessor at battle start, applying stat bonuses and other effects during combat.

Interactive Teyvat Map

The Research button has been replaced with a Map button that opens a full interactive map of Teyvat. Available to all players regardless of role.

  • Auto-updating map image: Downloads the latest hi-res Teyvat map from the Genshin Impact Wiki (~25MB). Cached locally and re-checked every 7 days so you always have the most current version. Progress bar shown during download.
  • Pan & zoom: Right-click or middle-mouse drag to pan. Scroll wheel zooms centered on your cursor position. Zoom buttons (+/-/Reset) in the bottom-right corner.
  • Official POI markers: Domain locations, Statue of The Seven markers, and world boss locations are fetched from the official HoYoLAB API with their actual game icons. All 170+ markers manually calibrated to the wiki map.
  • Domain artifact info: Click any artifact domain to see which sets drop there. Domains with defined sets show the full 2-piece and 4-piece effects from the DnD adaptation. Undefined sets show "Set effects not yet defined." Artifact info also appears in hover tooltips.
  • Player markers: Each player has their own color and can place markers in 6 shapes (circle, diamond, star, triangle, square, cross). Click to add a note, edit, or delete. Anti-aliased rendering with drop shadows for clean visuals.
  • Marker sync: When online, markers sync through the host to all players. Each player owns their markers in their color. Offline players use local save and merge on reconnect.
  • Ctrl+click ping: Hold Ctrl and click anywhere to ping a location. A pulsing ring in your player color appears with your name for 4 seconds, visible to all connected players. Great for pointing out destinations during group planning.
  • City labels: Major cities labeled on the map — Mondstadt, Liyue Harbor, Inazuma City, Sumeru City, Court of Fontaine, Natlan, and Nod Krai.
  • Draggable detail panel: The marker/POI info panel can be repositioned by dragging its title bar.

Crafting Recipe Overhaul

Crafting recipes have been reworked from the ground up with a new data format and improved UI.

  • Multi-ingredient recipes: Recipes now support multiple ingredient slots, each with multiple valid options. For example, a weapon recipe might need "Any Mondstadt Billet" in one slot and "Crystal Chunk x5" in another.
  • Flat recipe format: Replaced nested Resource references with flat recipe_text strings for clean inspector editing. Each line is an ingredient slot, bracket-tagged by type.
  • Gem recipes: Elemental gem crafting recipes now show as separate alternative lines for clarity.
  • Improved crafting UI: Larger recipe cards, click anywhere on a card to select it, icons pulled from all resource folders for better coverage.

Balance Adjustment

Brian F. Nature Charged Attack — Attack within 12 tiles. Nature damage. Add damage equal to the tiles travelled. If target Rooted, +5 damage (prev. +3) OR 2x damage (whichever is higher) and gain ½ usual amount of burst charges. Move no tiles. Gain no burst charges if not-rooted.

NOTE — Your numbers came in lower than expected comparatively to everyone else, the above buff should increase your baseline threshold and enable you to still build burst charges albeit slower than normal. Note as well this attack has always dealt Nature damage which means it scales off of your EM not your Attack stat even though it's a charged attack.

Brian C. Nature Skill Attack — Choose a tile within 3 (prev. 2) tiles. Enemies on that tile and adjacent tiles take Nature damage.

Escalation: d4 → d6 → d8 → d10 → d12 → d20 (must roll above half to succeed), Damage = cumulative result of success rolls (pre-multiplier). Failure results in 0 damage. Gain 1d4 burst charges × ER after. For each escalation roll done successfully above a D12 (i.e. D20, D20+D4, etc.), lower the crit threshold of that hit by 5, and add 0.5 to your Crit Damage for that specific hit.

NOTE — Increased reward/incentive to continue higher escalation chains hehehe. Also gave you an extra tile of range just so it feels a little bit smoother, 2 felt too restrictive.

Brian C. Nature Passive — Before an escalation roll, lose 2 HP to reduce the requirement by 1 (multiple times allowed). The requirement cannot be reduced below 1. For every 5 reductions in the same escalation chain, the health cost to reduce the requirement is doubled. (i.e. first 10 health is as described above, the next reduction after that costs 4 HP per point reduction, after another 5 that goes up to 8 HP per point reduction, etc.).

NOTE — Still lets you achieve your talent at the same cost but guards against just stacking HP endlessly, high escalations should feel like they have some extent of risk but a reward that feels worth chasing.

Bug Fixes

  • Fixed null value crashes in character stat calculation when loading from JSON data with null fields (Shield_Health, Shield_Duration, etc.).
  • Fixed stale hosts lingering in the LAN discovery list — hosts that stop broadcasting now expire after 3 seconds.
  • Fixed crafting recipe tests using wrong data source (Global.CRAFTING_RECIPES returns dicts, not CraftingRecipeData).
  • Added 15 missing scene instantiation tests to the test suite.

  • Fixed offline Manage Inventory panel only filling a quarter of the screen. The player hub is a Node2D, so Control anchors didn't work. The panel now uses a CanvasLayer with explicit viewport sizing and renders above toast notifications.
  • Fixed offline region defaulting to Inazuma for Brian C. Region changes update the Party table, but the offline loader was reading from the Character table (which was stale). Now reads from the Party record first, which is the actual source of truth for region.

  • Added artifact detail fields to Manage Inventory. When adding artifacts in offline mode, you can now set the slot type (Flower, Feather, etc.) and both stat lines before adding.
  • Fixed crafting migration combining all recipe variants as required slots incorrectly — now produces proper slot-based recipes.
  • Fixed recipe type matching not recognizing bracket-tagged ingredient types.
  • Fixed empty recipe lines appearing in the crafting UI for recipes with no ingredients defined.
